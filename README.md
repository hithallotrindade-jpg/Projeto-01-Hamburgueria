# 🍔 Bino's Burguer

Site demonstrativo de uma hamburgueria artesanal, desenvolvido como projeto de estudo e portfólio em desenvolvimento web.

## 📌 Sobre o projeto

O Bino's Burguer é um site que apresenta o cardápio de uma hamburgueria e permite que o cliente monte seu pedido antes de encaminhá-lo pelo WhatsApp.

O projeto foi desenvolvido para praticar conceitos de desenvolvimento web e criar uma experiência simples e intuitiva para o usuário.

## ✨ Funcionalidades

- Cardápio com imagens, descrições e preços.
- Layout responsivo para computadores e celulares.
- Carrinho de compras interativo.
- Adição e remoção de produtos.
- Controle de quantidades.
- Cálculo automático de subtotais e valor total.
- Contador de itens no carrinho.
- Campo obrigatório para o nome do cliente.
- Campo opcional para observações do pedido.
- Geração de mensagem personalizada para finalizar o pedido pelo WhatsApp.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura do site.
- **CSS3:** aparência visual e responsividade.
- **JavaScript:** interatividade, carrinho e cálculo dos pedidos.

## 📂 Estrutura do projeto

- `index.html` — estrutura da página.
- `style.css` — estilos e layout responsivo.
- `script.js` — lógica do carrinho e finalização dos pedidos.
- `img/` — imagens utilizadas no cardápio.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no computador.
3. Abra o arquivo `index.html` no navegador.

## 📲 Pedidos pelo WhatsApp

O site gera uma mensagem com os produtos selecionados, as quantidades, o valor total, o nome do cliente e as observações informadas.

**Importante:** o número utilizado durante o desenvolvimento é fictício e precisa ser substituído pelo número correto antes de utilizar o site em um negócio real.

## 🎯 Objetivo do projeto

Praticar HTML, CSS e JavaScript por meio do desenvolvimento de um site funcional, além de demonstrar conhecimentos iniciais em desenvolvimento web.
